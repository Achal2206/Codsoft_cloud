☁️ Cloud Storage Architecture (Task 1)

Cloud Architecture: Supabase Cloud Storage

Built with Node.js Express and the official @supabase/supabase-js SDK. Files are stored directly in a scalable Supabase Cloud Storage Bucket, supporting automated signed download links, real-time public/private access control, and SHA-256 cryptographic integrity verification.

🛡️
SHA-256 Checksum

Every file is verified via cryptographic hashing during upload to ensure file integrity in transit.

⏱️
Signed Shareable Links

Generates tokenized presigned URLs with configurable TTL (15m, 1h, 24h, 7d).

🔐
Granular ACL

Toggle files between Public and Private permissions on demand without re-uploading.

⚡
Streaming Engine

Node.js readable stream piping for zero-RAM memory leaks on large downloads and previews.
