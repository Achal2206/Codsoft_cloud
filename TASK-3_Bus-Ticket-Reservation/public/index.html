☁️ High-Traffic Cloud Architecture (Task 3)

Concurrency & Double-Booking Protection

Online ticket reservation systems experience intense concurrent surges. To prevent double-booking, the system employs an Optimistic Locking & Ephemeral Seat-Lease pattern.

⏱️
Atomic 5-Min Lease

When a passenger selects a seat, an atomic lease lock is granted with an expiry timestamp. Other passengers see this seat as "On Hold".

🧹
Automated Sweeper

A background worker continuously clears abandoned holds, instantly returning seats to the available pool without database locks.

⚡
Scalable Throughput

Stateless API endpoints ready for Azure Functions, Azure App Service, or Azure Container Apps behind Azure Front Door / Load Balancer.

🛡️
ACID Integrity

Transactions are validated before commit to guarantee that no two users ever receive the same seat.
